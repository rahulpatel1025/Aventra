# Aventra Tech Solutions

[Visit Aventra Tech Solutions](https://aventratechsolution.com/)

An industry-aligned EdTech platform offering specialized courses in FinTech Systems and OData API Development. Built with a modern full-stack architecture, Aventra features secure video delivery, seamless payment integrations, and robust user authentication.

## 🚀 Features

* **Secure Video Delivery:** Utilizes AWS S3 and CloudFront for high-performance, secure video streaming of course content.
* **Robust Authentication:** Integrated with Clerk for secure user sign-ups, logins, and profile management.
* **Course Management & Progress:** Track user progress through modules, including interactive quizzes and video completion statuses.
* **Secure Payments:** Integrated with Razorpay for handling course purchases, including structured EMI payment options.
* **Responsive UI:** Built with React and Bootstrap for a seamless learning experience across all devices.

## 💻 Tech Stack

* **Frontend:** React.js (Vite), HTML5, CSS3, Bootstrap
* **Backend:** Node.js, Express.js
* **Database:** MongoDB Atlas (Mongoose)
* **Authentication:** Clerk
* **Cloud & Infrastructure:** AWS (EC2 for backend hosting, S3 & CloudFront for secure media storage/delivery)
* **Payment Gateway:** Razorpay
